# FASCO

Магазин сучасного жіночого одягу на HTML, CSS і JavaScript.

## Запуск

Відкрийте папку проєкту через Live Server у редакторі коду та перейдіть на index.html. Для сайту не потрібні npm, Python або встановлення залежностей.

## Сторінки

- index.html — головна, пропозиції, нові надходження, відгуки.
- shop-page.html — каталог, пошук, фільтри та сортування.
- product-page.html — товар, галерея, форма запитання, мінікошик.
- minicart-page.html — товар із відкритим мінікошиком.
- cart-page.html — кошик і демонстраційне оформлення.
- 404.html — сторінку не знайдено.

## JavaScript

assets/js/store.js містить каталог і спільну модель кошика. assets/js/main.js керує поведінкою сторінок. Дані кошика зберігаються у localStorage браузера.
