# FASCO

Магазин сучасного жіночого одягу на HTML, CSS і JavaScript.

## Запуск

Відкрийте папку проєкту через Live Server у редакторі коду та перейдіть на index.html. Для сайту не потрібні npm, Python або встановлення залежностей.

## Сторінки

- index.html — головна, пропозиції, нові надходження, відгуки.
- shop-page.html — каталог, пошук за назвою, фільтри розміру, кольору й ціни, сортування за ціною.
- product-page.html — товар, галерея, форма запитання, мінікошик.
- minicart-page.html — товар із відкритим мінікошиком.
- cart-page.html — кошик і демонстраційне оформлення.
- 404.html — сторінку не знайдено.

## JavaScript

assets/data/products.json містить масив об’єктів товарів. assets/js/store.js завантажує його через fetch та містить функції кошика. assets/js/main.js керує поведінкою сторінок. Дані кошика зберігаються у localStorage браузера.
## Завантаження даних

Для роботи fetch запускайте сайт через Live Server або GitHub Pages. Відкриття HTML подвійним кліком через file:// не підходить. Товари завантажуються з assets/data/products.json. У разі помилки запиту або некоректних даних з’являється повідомлення та кнопка повторної спроби. Збережений кошик при помилці не перезаписується.

Пошук перевіряє лише назву товару. Можна вибрати один розмір, один колір та один діапазон ціни, а також відсортувати товари за ціною. Нижня межа діапазону включається, верхня не включається: товар за $50 належить до $50–$100. Повторне натискання вибраної ціни скидає цю умову. Бренди, колекції та теги в бічній панелі залишені як елементи макету.
